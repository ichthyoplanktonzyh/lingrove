Lingrove（拾语）0.7.1 / build 3 公开测试预发布版。自动补全与语言学习均为核心能力；此版本汇总 0.5.1 测试版以来的功能和修复。

## 下载与安装

下载 **Lingrove-0.7.1-test-universal.dmg**，打开后将 Lingrove.app 拖入 Applications，推出磁盘映像后启动。更新前请退出旧版，备份重要学习数据；测试安装包时请退出 Lingrove Dev。安装说明位于 DMG 内的 INSTALL.txt，也可单独下载 INSTALL.zh-CN.txt。

要求 macOS 14 或更新版本，包含 Apple Silicon 和 Intel 架构。Apple Intelligence 还要求受支持的 Mac 和 macOS 26 或更新版本。安装包不包含模型权重、用户数据或服务商凭据。

这是 **ad-hoc 临时签名、未使用 Developer ID 签名或公证的测试版**，没有自动更新。首次打开方式见安装说明。Intel 实机与其他 Mac 的首次下载安装流程尚未完成本次验收。

## 本次更新

- 生词本支持表达、义项、原文例句、笔记、标签、收藏与复习，以及手动创建、CSV/TXT 词表和例句导入。
- 新增意义索引：以多语言意义节点浏览相关表达，管理具体用法、意义关联和检索线索。
- 词库分离词条目录、不可变来源证据、解释判断与个人收藏。取消收藏保留知识和原始证据；旧数据迁移与引用关系由本地数据库维护。
- CLI 增加版本 2 原子资源操作和修订冲突保护，允许外部工具组织词库与意义关系；提供可安装的 CLI 使用技能。
- 表达辅助支持朗读、收藏和行内操作；首次引导提供推荐模型配置。
- 阅读翻译结合 OCR、辅助功能、选区和原句证据，改进上下文获取、语境解释及卡片交互。
- 词典使用 Lingrove 自有卡片，支持系统词典和导入的 MDX/MDD；可选网络词典需显式开启。
- 修复输入法提交、增量翻译、模型任务隔离和若干补全、设置及阅读交互问题。

## 验证与限制

- 本次词库、CLI、复习和相关界面回归：207 项测试通过；表达辅助面板与设置页：7 项测试通过。
- 严格 SwiftLint 无告警；1,714 个源键、3 个字符串表、15 种界面语言的本地化结构校验通过。
- 上述为本次针对性验证，不代表重新执行了全部测试或完成全部宿主应用的人工验收。
- 语境解释与模型输出可能不准确；意义分类由用户或外部工具明确整理，不会自动发起分类模型请求。
- 本地模型和 OCR 在 Mac 上运行。明确选择 Endpoint 或启用网络词典后，对应内容会发送至所配置服务。
- Lingrove 与 Lingrove Dev 的数据和权限独立。临时签名更新可能需要重新授权辅助功能、输入监控或屏幕录制。

SHA256SUMS.txt 提供下载完整性校验；build-info.json 记录版本、架构、签名与精确源码提交。反馈请至 [GitHub Issues](https://github.com/ichthyoplanktonzyh/lingrove/issues)，请勿上传私人输入或密钥。
