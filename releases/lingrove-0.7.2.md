Lingrove（拾语）0.7.2 / build 4 公开测试预发布版。包含 0.7.1 之后截至 `c66fb60` 的最新 macOS 功能与修复；自动补全与语言学习均为核心能力。

## 下载与安装

下载 **Lingrove-0.7.2-test-universal.dmg**，打开后将 Lingrove.app 拖入 Applications。更新前请退出旧版并备份重要学习数据；替换后推出磁盘映像，再从“应用程序”启动。测试本包时请先退出 Lingrove Dev。安装说明位于 DMG 内的 INSTALL.txt，也可单独下载 INSTALL.zh-CN.txt。

要求 macOS 14 或更新版本，包含 Apple Silicon 和 Intel 架构。Apple Intelligence 还要求受支持的 Mac 和 macOS 26 或更新版本。安装包不包含模型权重、用户数据或服务商凭据。

这是 **ad-hoc 临时签名、未经 Developer ID 签名或公证的测试版**，没有自动更新。首次打开方式见安装说明。Intel 实机与其他 Mac 下载后的首次安装流程尚未完成本次验收。

## 本次更新

- 生词本改进表达浏览、意义详情和图谱布局，统一语义信息展示。
- 增加可扩展的意义分类目录、层级分类选择与树形导航；补充多语言分类说明和来源资料。
- 新增本地多语言表达检索：可用自然语言描述想表达的意思，在已收藏的义项中查找。Qwen3 Embedding 0.6B Q8_0 权重可从搜索提示或模型设置按需下载，约 639 MB；索引与检索均在本机进行。
- 检索在排序前过滤低相关候选，约束字面匹配的范围，并显示实际命中数量；未安装语义模型时保留关键词查找。
- CLI 增加按学习材料整体捕获的入口，可原子整理来源证据、收藏与语义关系，并提供意义分类资源和相应文档。

- 修复原生助手通用架构校验与新依赖目录的补丁比对兼容性，保持所有助手包含两种处理器架构。

## 验证与限制

- 本次 Release 配置下的词库分类、持久化、CLI、界面和检索回归：90 项通过、2 项可选原生界面测试跳过，无失败；实际运行了跨语言检索与 43 条相关性用例的模型测试。
- 121 项 Python 工具测试通过，严格 SwiftLint 通过；1,758 个源键、3 个字符串表、15 种语言的本地化结构校验通过。
- 以上为本次针对性验证，不代表重新执行全部测试或完成所有宿主应用的人工验收。

- 分类由用户或外部工具明确整理，不会自动调用模型进行分类。语义检索可能遗漏相关项，也可能混淆意思接近或相反的表达；请结合义项与原句判断。
- 本地模型、语义索引与 OCR 在 Mac 上运行。明确选择 Endpoint 或启用网络词典后，对应内容会发送至所配置服务。
- Lingrove 与 Lingrove Dev 的数据和权限独立。临时签名更新可能需要重新授权辅助功能、输入监控或屏幕录制。
