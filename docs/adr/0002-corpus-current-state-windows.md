# 语料同步保留当前值与固定读取窗口

语料内容没有要求保存每次编辑的历史正文；在增量日志中永久保存旧原文、笔记或
释义，会让修改和删除后的私人文本继续留存。因此规范实体只保存当前值与删除身份，
提交日志只记录工作区、生词本、操作组、成员、实体身份及提交序号，不复制语言材料。

后续增量传输以固定高水位的当前状态窗口合并受影响实体，完整准备并原子应用整个
窗口；不能把不同时间读到的实体页直接应用，也不能把只含身份的日志当作历史事件
回放。跨请求分页须使用有期限的固定清单/快照并在确认后清理，构建这条路径之前
不开放客户端 pull。整组写入及幂等确认仍遵循 [ADR 0001](0001-versioned-notebook-sync-groups.md)。

这避免了不必要的正文历史副本，代价是需要明确建设并验收固定窗口与大数据暂存。
复习的追加式评分历史、仍被其他内容引用的原始证据和设备专用的本地数据继续遵守
各自所有权规则，不借此自动删除。
