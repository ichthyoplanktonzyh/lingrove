# 语料同步保留当前值与固定读取窗口

语料内容没有要求保存每次编辑的历史正文；在增量日志中永久保存旧原文、笔记或
释义，会让修改和删除后的私人文本继续留存。因此规范实体只保存当前值与删除身份，
提交日志只记录工作区、生词本、操作组、成员、实体身份及提交序号，不复制语言材料。

增量传输以固定高水位的当前状态窗口合并受影响实体，完整准备并原子应用整个
窗口；不能把不同时间读到的实体页直接应用，也不能把只含身份的日志当作历史事件
回放。跨请求分页须使用有期限的固定清单/快照并在确认后清理，构建这条路径之前
不开放客户端 pull。整组写入及幂等确认仍遵循 [ADR 0001](0001-versioned-notebook-sync-groups.md)。

这避免了不必要的正文历史副本，代价是需要明确建设并验收固定窗口与大数据暂存。
复习的追加式评分历史、仍被其他内容引用的原始证据和设备专用的本地数据继续遵守
各自所有权规则，不借此自动删除。

内部窗口实现使用与写入相同的生词本行锁，在锁内将规范记录物化成临时字节页。
bootstrap 包含全部当前记录和删除身份；incremental 按日志选择范围内受影响的身份，
每个身份只返回锁内的当前值。页内容是显式 `CorpusRecord[]` JSON 的连续 UTF-8
字节流，256 KiB 一页，可以跨实体和码点，通过 base64 传输。每页哈希、顺序描述符
哈希与绑定作用域/高水位/计数的 manifest 一起验证，不为累计变大的合法实体另设
一个无法跨越的页面大小限制。

窗口属于创建它的账户和 replica，membership/book/replica 删除级联清正文。有效期从
物化末尾的数据库时钟起固定十五分钟，请求和重放不续期。主动释放与既有每分钟维护
任务都只清临时缓存，不修改规范语料、提交日志或客户端游标。到期维护分批删除最多
128 页，再删除已空的过期 header；不把超大窗口交给一次无界级联。维护调用已接入
代码，实际云端部署/调度尚待后续验收；逻辑过期与物理回收分别核对。
