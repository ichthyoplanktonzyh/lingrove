## 当前 Note 引擎写入

以下为修正“来源删除后编辑”的边界行为之后，当前代码在新建等价合成种子上的三次中位数。
只计公共写入调用；草稿、完整数据读取、连接准备与结果校验均在计时外。每次保留全部卡片 ID、调度状态及 1,000 条评分记录。
此组与下方应用层测试的夹具和计时范围不同，不能相减估算某个内部阶段的耗时。

## 本批结果与后续候选

单条写入已收窄到相关 Note、类型、成员和来源，不再重复准备整个工作区。类型共享修改仍更新全部引用者。
语料模型不再包含旧 `review`、`reviewCards`、`reviewTemplates`；例句追加、修改及整体义项合并保留。
来源删除/合并后再编辑、失败回滚、自定义字段保留和条件模板新增卡片均有实际存储测试。

2 万词条下，包含数据刷新的单条 Note 编辑为 482.757ms，评分并刷新为 511.957ms，
首次进入复习为 704.549ms（以上各为一次扫描观察）。调用路径在保存后重新加载完整复习快照；
结合引擎写入的毫秒级耗时，提示读侧加载/投影值得下一轮分段测量和增量刷新，
不能直接将两种夹具的差值归因于某一个方法。

全量检索准备与列表文字筛选的三次中位数约 541ms / 534ms，完整语料读取约 8.46s。
`corpus.load.first` 强制读取完整规范语料，不能当作分页首屏准备时间；本轮未重跑前一批独立的分页/缺失证明窗口。
完整备份写出/恢复约 2.29s / 7.12s，为一次扫描观察；备份指语料与所属图片，不包含独立的 Note/Anki 本地状态及评分历史。
共享模板、备份和全量读取的真实全库工作仍有批处理/派生投影方面的研究空间，本批保留现有原子更新策略。

## 应用层计时口径

配置：Release / arm64 / ENABLE_TESTABILITY=YES；所有样本通过测试调用生产业务代码，没有模拟点击。

共 84 个计时窗口、378 个样本。其中 35 项每档独立重复 3 次；其余为每档单次完整扫描。

表中列名是初始词条数量，单位为毫秒。样本数大于1时显示中位数（最大值）；样本数为1时只显示单次观察值，没有统计稳定性保证。重复测量使用接近种子状态的独立副本；扫描内按固定顺序执行全部操作。

首次加载指新连接和新模型的首次访问；不含应用组合根/Repository初始化，也没有清空操作系统文件缓存。后续写入使用另一条等价内容，不是重复保存造成的无操作。

每个试次从同一档合成种子重新复制，按固定顺序执行；试次之间互不累计。单次试次内会新增和移除少量内容，原始样本记录每项执行前后的可见词条数。

存储总耗时计到 VocabularyStore 应用结果并发布状态为止；不含 SwiftUI 实际绘制、等待动画、下载、远端网络或模型生成。检索、列表和图谱投影另行列出。CLI不含进程启动和邮箱IPC。

阶段窗口使用独立调用，不能将不同调用的中位数相加解释成一次请求的总耗时。图片用80×40的合成PNG，不能代表大图片或媒体密集库。

两组删除样本同时改变了位置与语义关联：第59词条有关联，倒数第2词条无关联。它们是两个真实场景，不是隔离关联因素的对照实验，不能将差异全部归因于关联。引擎分段删除使用第65词条。

微秒量级的缓存读取接近测试调用与计时开销，不据此比较微小差异。

个人笔记变化的检索计时没有改变检索字段，主要验证避免多余重建；它不能代表义项定义或共享义改变后的检索重建耗时。

- 共享引擎全量 148 项通过（126 Swift Testing、22 XCTest）；包含修正后的删除/合并来源场景。随后仅清理了两组测试的无用变量和过时标题，并定向编译/执行这两组。

- 原生首次广泛回归 171 项通过、3 项旧 CLI 夹具失败、1 项可选桌面旅程未运行；夹具修正后 CLI 33 项通过。修正来源读取后相关复习原生 8 项通过，正式计时的全部正确性断言通过。
- Release 隔离宿主构建、签名、100 词条 smoke 和正式两档测量均通过；没有使用真实点击或真实 Anki/云服务。
- Strict SwiftLint 与差异检查通过。构建缓存、复制的依赖、私有宿主和合成库按各运行清理；最终状态见验证记录。
