Lingrove（拾语）v0.5.1（build 2）测试预发布版
安装与快速体验
本说明在 DMG 根目录中的文件名为 INSTALL.txt。

适用范围

此说明适用于 Lingrove 的本地验收包和公开测试包，供自愿参与测试的用户使用。
它不是正式稳定版，也没有自动更新。包内应用使用 ad-hoc（临时）签名，尚未使用 Apple
Developer ID 签名或公证。构建来源和架构以安装包旁的 build-info.json 为准；本地验收包
尚未公开发布。公开测试包请从下面的官方 Releases 页面下载 DMG，无需使用终端。
本说明已附在 DMG 内：
https://github.com/ichthyoplanktonzyh/lingrove/releases

此应用要求 macOS 14 或更新版本。通用版本包含 Apple Silicon（arm64）和 Intel（x86_64）
两种处理器架构。本包在 Apple Silicon 本机进行构建、包完整性检查和基础启动验证；Intel
实机与其他 Mac 下载后的首次安装流程仍需测试者验证。这不代表 Intel Mac 已经验证通过，
也不代表全新 Mac 上 Gatekeeper 的首次放行流程已完成验证。

安装包不含 GGUF、翻译模型、解释与表达模型、语音模型或音频解码器权重，也不含任何模型
服务商的账号或密钥。
按需下载本地模型可能需要数 GB 空间。Apple Intelligence 补全要求受支持的 Mac 运行
macOS 26 或更新版本；否则可下载兼容的 GGUF 模型，或自行明确配置 OpenAI 兼容服务。
使用远程服务时，相关任务的文字请求会发送到你配置的服务端。翻译和解释与表达也使用各自
独立配置的本地模型或服务端。文字转语音也有独立的 provider、模型及服务凭据。
DMG 根目录还附有 LICENSE、THIRD_PARTY_LICENSES.md、SpellingDictionaries-NOTICE.md、
LearningExpressions-NOTICE.md，以及 ThirdPartyLicenses/ 第三方许可资料目录。

一、安装并启动

1. 从上面的官方预发布页面下载 Lingrove-0.5.1-test-universal.dmg。
2. 双击打开 DMG，将 Lingrove.app 拖到 Applications（应用程序）快捷方式。
3. 安装完成后，在 Finder 侧边栏中推出 Lingrove 磁盘映像。
4. 从“应用程序”文件夹启动 Lingrove。不要直接从已挂载的 DMG 运行它。

因为这是尚未公证的测试版，macOS 可能提示无法验证开发者。如果你确认安装包来自上述
官方预发布页面，可以先尝试打开一次，再到“系统设置”→“隐私与安全性”
页面靠下的“安全性”区域选择“仍要打开”（Open Anyway），然后按系统提示确认。也可先查看
Apple 的 Gatekeeper 说明：https://support.apple.com/en-us/102445

如果 macOS 提示应用“将损坏你的电脑”，或提示签名损坏、文件已损坏，请停止操作并联系
测试团队。不要绕过这类提示，不要移除隔离标记，不要关闭 Gatekeeper。

二、首次授权

补全功能需要 macOS 的“辅助功能”（Accessibility）和“输入监控”（Input Monitoring）
权限。首次启动后，按系统提示打开“系统设置”→“隐私与安全性”，分别允许 Lingrove 使用
这两项权限。完成首次授权后，请退出 Lingrove 并重新启动一次；这样可以让键盘输入监听器
在新权限状态下启动。

“屏幕录制”权限用于截图视觉上下文、主动框选区域 OCR，以及鼠标取词的 OCR 回退。
区域 OCR 和鼠标取词仅在主动触发时读取相应屏幕范围。不使用这些能力时无需授予此权限。

Lingrove 与 Lingrove Dev 是两个独立应用，使用不同的设置和模型存储位置；测试版不会自动
导入 Dev 版的数据。测试本安装包时，请先退出 Lingrove Dev，并确保同时只运行一个 Lingrove
实例，以免重复注册全局键盘监听；无需卸载 Dev 版。由于测试包使用临时签名，重新安装或
替换后 macOS 可能要求再次授予权限。未来的正式版需要先完成 Apple Developer ID 签名与
公证设置；签名切换后也请检查权限状态。

三、体验自动补全

1. 从菜单栏打开 Lingrove 设置，在“引擎与模型”（Engine & Model）中选择一种补全方式。
   Apple Intelligence 仅适用于受支持的 Mac 和 macOS 26 或更新版本；本地方式需要你自行
   下载 GGUF 模型；服务端方式需要你自行配置地址和凭据。本安装包不包含这些模型或凭据。
2. 在任意受支持的文本输入框中输入几句话，观察光标旁是否出现灰色续写建议。
3. 按 Tab 接受建议。需要时可在“快捷键”（Shortcuts）设置中更改逐词接受和接受整条建议
   的按键。
4. 如果希望看到当前输入框的焦点指示，可在“外观”（Appearance）中打开“显示字段指示器”
   （Show Field Indicator）。

四、体验翻译、阅读翻译与朗读

翻译与表达辅助

1. 首次引导的模型步骤可点击“使用推荐配置”，自动补齐缺少的模型并开始下载，同时开启补全、
   写作与选区翻译、表达辅助。解释和表达辅助共用一个模型，新用户使用系统朗读。已有配置
   会保留，也可选择“手动配置”。系统权限需单独授权；下载完成前相应本地模型尚不可用。
2. 在“设置”→“语言学习”→“翻译”中配置源语言与目标语言。输入并确认输入法候选词，
   稍停后可查看当前句译文；主动选区优先处理选中文字。
3. 点击卡片的替换操作，或按默认 Control+Option+T，将译文写回对应的当前句或选区。
   原文范围已变化时，旧结果会失效。Option+T 用于展开或收起详情。
4. 在“语言学习”→“解释与表达”中开启表达辅助，在光标处输入 ?? 或 ？？，描述想表达的
   意思，稍停后查看候选，按 Enter 或 Tab 插入，按 Escape 取消。此功能可独立于翻译开启。

阅读翻译

1. 在“语言学习”→“翻译”的阅读翻译区域，分别开启需要的入口并设置阅读目标语言。
2. 在“设置”→“App”中为目标应用允许相应入口。快捷键统一在“设置”→“快捷键”管理。
3. 选中文字后按默认 Option+Shift+T；或者启用选区图标后点击图标。
4. 将鼠标指向文字，按默认 Control+Shift+T 取词翻译；可读文本优先通过辅助功能获取，
   必要时使用 OCR 回退。当前版本主要翻译指向的词，尚未提供完整的语境词义消歧。
5. 按默认 Control+Option+Shift+T 框选屏幕区域，将 OCR 获取的文字交给同一翻译流程。
   Escape 可取消框选。阅读卡片保持只读，不提供写回其他应用的替换操作。

朗读

1. 点击预览卡或详情卡中文字旁的小喇叭进行朗读，再次点击停止。卡片根据所点文字自动识别
   朗读语言；设置页试听使用所选试听语言。
2. 在“引擎和模型”→“文字转语音”选择 Apple 系统声音、本地模型或 Endpoint。
   系统声音依赖 Mac 已安装的相应语言声音。本地 Qwen3-TTS Base 模型需要匹配的 GGUF
   模型与音频解码器，可按需下载，并可选择参考音频。切换模型后需要重新点击朗读或试听。
3. 本地语音通过 PCM 流播放，不为每次朗读保留 WAV 文件；本地模型需要加载时间并占用内存。
   Endpoint 需要兼容 /audio/speech，只发送本次朗读的文字及所选声音等请求参数。
4. 播放语速位于“语言学习”→“朗读”。本地 TTS 的“高级设置”提供采样参数；系统声音和
   Endpoint 没有这组生成参数。Base 模型不支持风格指令，当前 Endpoint 接口也尚未接入。
   性能页可按 TTS 请求类型查看已开启记录的指标。

以上是默认快捷键，若已自定义，请以“快捷键”设置中显示的配置为准。自动补全与语言学习可
分别启用。新安装不会自动继承 Lingrove Dev 的设置、凭据、权限或模型。

五、替换测试版本与反馈

新测试版不会自动安装。更新时先退出 Lingrove，再将新 DMG 中的 Lingrove.app 拖入“应用
程序”并选择替换；随后推出 DMG，再从“应用程序”启动新版本。重要数据请自行备份。
输入历史记录是可选的加密功能，默认关闭；测试版不会自动导入 Lingrove Dev 的历史记录。

请在 GitHub Issues 提交反馈：https://github.com/ichthyoplanktonzyh/lingrove/issues
请附上应用版本和 build、macOS 版本、Mac 芯片型号，以及能够重复问题的步骤。不要附上
完整模型提示词、包含私人输入的日志、密码或服务端密钥。如需提供诊断片段，请先删除其中的
个人文字和凭据。

六、可选：文件完整性检查（技术用户）

普通安装不需要下载 SHA256SUMS.txt，也不需要运行终端命令。遇到下载问题，或希望自行
核对文件时，可以额外下载该校验文件，与 DMG 放在同一个文件夹，在“终端”中进入该目录
并运行：

    shasum -a 256 -c SHA256SUMS.txt

显示 OK 表示 DMG 与发布方记录的文件一致；校验失败时请从官方页面重新下载，或联系
测试团队。此检查仅验证文件一致性，不代表软件安全，也不能替代 Apple 签名或公证。

Apple Developer ID 分发说明：https://developer.apple.com/developer-id/
